# G13: Pro-AV control copilot (G:pattern_transfer:1)

Verdict: WEAK (not dead, not strong). Gate date 2026-10-25. About 22 searches and fetches.

## What I found

**Direct competitors: none found for Q-SYS or Extron programming assistance, but the real competitor is a substitute.**
- XTEN-AV XAVIA is design, BOM and proposals only. No control-code output found. (xtenav.com)
- AVPro Tech Sage is partner-only support, built on Claude Sonnet 4.5. Not a coding tool. (avproglobal.com)
- Crestron previewed an AI mode in Configure Pro at CEDIA 2026 (builds projects from natural language; one trade report says early 2027). Not code generation, but the platform vendor is moving. (cepro.com)
- Open-source `q-sys-mcp` (github.com/reowens/q-sys-mcp) already lets any LLM agent read and write controls on a Core or on Designer in Emulate mode over QRC (TCP 1710). The "agent talks to the emulator" piece is free today.
- Q-SYS ships a VS Code script editor with IntelliSense and a Block Controller that generates valid Lua. Extron has moved its programming environment to VS Code plus the ControlScript Deployment Utility. So the buyers already work in editors where Cursor, Copilot and Claude Code run.
- Frontier models are already used by Crestron programmers (Reddit CCP-exam thread: "pretty good with C#", SIMPL+ needs tweaking). AVNation's "A State of Control" podcast has an AI episode ("Silent Intern"). A Q-SYS Developer Spotlight interviewee says he would integrate gen AI more, and that prompting often takes longer than just writing the code. Both sides of the thesis in one source.
- Human substitutes: Controlworks and Avendor (275+ clients) sell outsourced AV programming.
- Adjacent: Copia Automation ($26M on 2026-06-16, $55M total) is mainly PLC version control, backup and recovery, not code generation; the idea overstated it as proof of an AI-codegen category. PLC Copilot sells at $99-499/month flat with 0-1 reviews on Capterra, which is weak traction evidence for niche control-code copilots. Siemens Industrial Copilot has "12,000 engineers" with access.

**Technical facts that change the plan**
- Q-SYS Designer is Windows-only. Mac use is via Parallels (QSC tests Windows 11 guest on Apple silicon). Emulate mode is started from the GUI (F6); I found nothing on headless or CI use. The "test in the free emulator" loop therefore needs a Windows VM with a GUI session, or (better) a Lua mock of the Q-SYS API that runs anywhere. The second is also the real moat candidate.
- Emulate mode runs no DSP, only control logic. That fits Lua scripts, not audio behavior.
- QSC removed the Scripting and UCI license requirement in Designer 10 (2025). That grows the number of people who can deploy Lua, but it also means QSC is investing in scripting adoption and could ship its own AI helper.
- Extron: Global Scripter and ControlScript are gated to Extron Authorized Programmers (EAP). The current EAP online course is about 24 hours; price not shown publicly. Asher would need EAP to build and verify the Extron module. Crestron's tooling access rules were not confirmable from public pages; treat as unverified and probably gated.

**Market size (all rough)**
- Q-SYS: "over 3,500 certified programmers worldwide" (QSC, 2016). Crestron: 948 certified programmers in North America (2015); 116 Gold worldwide (undated). Reddit r/crestron about 11k members, r/CommercialAV about 29k.
- The idea's own 15-25k worldwide programmers is plausible but unverified. No source gives a current count.
- Salary: ZipRecruiter average Crestron programmer about $82k/year (about $39.50/hour; middle band $53.5k-$107k). Glassdoor median $95k. The idea's "$100-175/hr contractor rate" is a billing rate, not cost; freelance averages on ZipRecruiter are $35-48/hour. A $300/month seat is $3,600/year, about 4% of a median salary. It pays back if it saves roughly 8-10 hours a month. Plausible, but the buyer compares it to a $20-200/month general agent they may already pay for.
- Bottom-up: 20k reachable programmers x 5-10% penetration x $1.2k-3.6k/year = about $1.2M-7M. At the realistic price (below $150/month once general agents are the anchor) the AV-only number sits at $1-3M. The idea's own honest ceiling of $5-15M requires near-max price and 10%+ share.

**Reachability**
- Mentor: Marty Schaffel founded AVI, a predecessor of AVI-SPL. AVI-SPL did about $1.6B revenue (2024) and was sold to 26North in 2025; I could not confirm his current role there. Warm intros to programmers are plausible, but a $1.6B PE-owned integrator will send "upload client room code to a startup's AI" to security and legal. A two-week pilot "on their next real Q-SYS job" is probably blocked for a large integrator. Freelancers, programming shops and 5-50 person integrators, where the owner is the programmer, are the realistic first buyers.
- Workforce shortage is real but anecdotal (AVIXA May 2026 index: firms report difficulty finding and retaining staff). No vacancy or time-to-fill data found.

**Legal / age**
- No license or age wall for software that writes control scripts. Real frictions: (1) Extron EAP and Crestron tooling gates for building the Extron and Crestron modules; (2) copyright on manufacturer manuals for a "brand-neutral answer engine" (public manuals are readable, redistribution and training are a risk); (3) "brand-neutral" answers with manufacturer-paid placements is a credibility conflict and needs clear sponsored labeling; (4) client-data handling (designs contain IP addresses, sometimes credentials).

## Why weak, not kill
- Real unfilled gap in a named scarce workforce, a mentor-based wedge, a cheap test (under $3k, about 10 weeks).
- Not strong: the substitute is general agents plus free docs plus an open-source MCP, the platform vendors can ship the same, the vertical ceiling is a few million dollars, and the "big" path is Control4/Savant/BACnet/PLC, which are either dealer-closed or already funded and where Asher has no credibility.

## Sharpened version (does not shrink it)
Stop selling "a copilot that writes Lua" (commodity). Sell the part a general agent cannot do: **verified control code.**
1. Vendor-neutral simulation and eval layer: faithful mocks of Q-SYS Lua, Extron ControlScript and Crestron SIMPL#/C# plus device state machines (projectors, displays, DSPs, codecs), and a benchmark of real room tasks. Any agent (Claude Code, Cursor) runs generated code against it before it touches a Core.
2. Price by outcome, not seat: about $99-149/month individual, $1.5-5k/year per integrator team, or per-room verified program (about $100-300 against $800-4,000 of programming labor per room). Fixes the "$300 vs $20 Cursor" anchor.
3. Distribution: free open-core Q-SYS pack (agent skill + mock + 20 room templates) to get adoption and community credit; sell Extron and Crestron packs, team features, and the standardized-room-at-scale workflow (hundreds of near-identical Teams/Zoom rooms) to integrators.
4. Platform stance: apply to the Q-SYS Technology Partner Program; treat QSC as channel, not enemy.
5. The big path is a general verification layer for AI-written control code (building automation, home automation, PLC front ends), entered only after AV pays for itself.

Kill triggers at day 30: fewer than 3 of 10 programmers will run it on a real job; or fewer than 2 say they would pay above $100/month; or QSC/Crestron announces a Lua/C# AI helper.

## Numbers
- Cost to first revenue: about $2,500 (Windows/Parallels, API credits, optionally a Core 110f-class box for ground-truth testing, EAP course if Extron is in scope). The idea's $1,500 is light.
- Weeks to first revenue: about 10 (4-6 weeks to build the mock + skill + 30-task eval at 10-15 hours/week; 2 weeks pilots; first dollars around week 10).
- Median 5-year annual revenue: about $0.8M. Upside: about $12M (needs generalization).
- First customers: Controlworks-type and Avendor-type programming shops (hourly billers, productivity is margin), freelancers via r/crestron (about 11k) and r/CommercialAV (about 29k), AVNation "A State of Control" listeners, QSC Communities for Developers / Q-SYS Developer Summit attendees, The Farm and other plugin developers, 5-50 person integrators via the mentor's network, and university AV teams (Marty teaches at UF).
