- **`RESUME.md`**: exactly how to continue (steps 4-9).
- `01-discovery/`: 31 scout briefings, all 1,340 ideas, and the prompts used.
- `02-screening/`: cliché list, 133-problem taxonomy, the full tournament ranking (CSV), and 105 competitor reports.
- `03-evolution/`: 82 survivors (with judge notes and competitor research), plus the 214-candidate pool (offspring and hybrids with lineage).
- `skills/`: research and strategy method files the agents follow.
- `checkpoint/`: the complete machine state (`state/`), every agent's raw output (`journals/`), and every workflow script (`workflow_scripts/`).
